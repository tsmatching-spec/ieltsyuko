本文プレビュー

こんにちは、IELTSコーチの西野ゆうこです。

「リーディングの問題をたくさん解いているのに、6.0からなかなか伸びない…」

そんなことで悩んでいませんか？

もしかすると、その原因は復習のやり方にあるかもしれません。

以前、リーディングが1ヶ月で4.0から6.0に伸びた受講生さんのお話をしました。そのとき学習の軸に置いたのは、語彙力と間違い分析の2つでした。

このnoteでは、その間違い分析のやり方を詳しくお伝えします。私のコーチングの受講生さん全員にお伝えしている方法です。

間違えた問題を1問たりとも無駄にせず、次の1問の正解につなげる。最後まで読んでいただければ、なぜ今までの復習ではスコアが上がらなかったのか、どうすればリーディングのスコアを上げられるのかが、はっきり見えてくるはずです。

はじめに

本題に入る前に、皆さんの普段のリーディングの復習法について、少し耳の痛い話をさせてください。

もしあなたがリーディングの復習で、答え合わせをして解答を確認しているだけなら、残念ながらそれではスコアは上がりません。

IELTSのリーディングは、単語の意味が分かればいいというほど甘いものではありません。たった60分で長文を3つ読み、しかも合計40問を解き切らなければいけない。

ものすごく戦略性が問われるテストなんです。ネイティブスピーカーでさえ、戦略なしでは解き終えられません。だからこそ、私たちには戦略がとても重要なんです。

「正解の理由」と「間違えた理由」は別物

特に多いのが、問題を解いたあとに「なるほどね」と解答の場所だけを理解して終わってしまうパターンです。

でも、ちょっと考えてみてください。

解答が書かれている場所が分かったとしても、なぜ自分が間違えたのかを理解していますか？

実は、正解の理由を知ることと、自分が間違えた理由を理解することは、全く別物なんです。

リーディングの本質は「根拠を見つけること」

IELTSのリーディングで少しでも高い点数を取るために、一番重要なことは何でしょうか。

語彙力や文法力も、もちろん大切です。でも、本質的に求められているのは、本文の中から解答の根拠となる部分を正確に見つけ出すスキルなんです。

どんなに単語を知っていても、どんなに速く読めても、「ここが答えの根拠だ」という判断を間違えてしまえば、正解にはたどり着けません。

ここが問題の核心です。

あなたは、根拠を意識して問題を解いていますか？

IELTSのリーディングは、なんとなくで解答できるようには作られていません。必ず本文に明確な根拠があります。

そして、間違えるときにも明確な理由があるんです。その理由を知らないまま次の問題を解いても、また同じ間違いを繰り返すだけです。

間違い分析の3ステップ

ここからは、具体的な復習方法をお話しします。

ステップ1：解答の根拠に線を引きながら解く

普段、問題を解くときに、なんとなくで答えを選んでいませんか？

今日から必ずしてほしいのが、答えを選ぶときに、根拠となる本文に必ず線を引くことです。

線を引くことには、3つのメリットがあります。

① 自分の思考プロセスが見えるようになる
後から見ても、なぜその解答を選んだのかが明確になります。

② 「なんとなくの解答」を防げる
線を引けないということは、根拠が曖昧だということ。それに自分で気づけるようになります。

③ 復習の質が劇的に上がる
正解の根拠と比べることで、間違えた原因の分析が深まります。

ステップ2：答え合わせをする

次に答え合わせをして、どの問題が合っていて、どの問題が間違っていたかを確認します。

公式問題集には解説がありませんが、解説付きの教材や参考書をお持ちの方は、それを使って正解の該当箇所がどこにあるかを確認していきましょう。

ステップ3：正解の根拠に「別の色」で線を引く

間違えた問題は、正解の根拠が本文のどこにあるかを探します。

見つけたら、ステップ1とは別の色のペンで線を引きましょう。例えば、ステップ1では黒ペン、ステップ3では青ペンを使います。

最も重要なのは「線がずれた理由」の分析

ここからが、最も重要なポイントです。

ステップ1とステップ3で線を引いた箇所を比べて、2つが一致しなかった理由を分析していきます。

自分にこう問いかけてみてください。

  • 私はなぜ、この黒線の部分が根拠だと思ったのか？
  • なぜ、青線の部分だと見抜けなかったのか？

理由はいろいろありますが、よくある典型パターンを3つご紹介します。

パターン1：キーワードに飛びついてしまう

設問のキーワードが本文の近くに出てくると、深く考えずにそこを解答にしてしまうケースです。

解決法：キーワードがあるからといって飛びつかず、その部分が本当に設問への答えになっているか、文章全体の意味を正確に取りましょう。

パターン2：パラフレーズ（言い換え）に気づけない

例えば、main cause と primary driver。この言い換えに気づけないのは、語彙不足が原因です。

解決法：類義語や言い換えられている単語、意味が取れなかった単語をリストにして覚えていきましょう。

パターン3：Not Given の定義が曖昧

True / False / Not Given の問題で、なんとなく本文と矛盾している気がして False を選んでしまうケースです。

解決法：True・False・Not Given の違いをはっきりさせたうえで、本文にその記述が本当にないかを厳密にチェックしましょう。

原因を細かく分けて、毎回解決策を実行する

典型パターンを3つお伝えしましたが、もちろん原因はこれだけではありません。

  • 問題タイプについての理解が間違っていた
  • 問題文の意味や語彙が分からなかった
  • 文章の構造が分からなかった
  • 指示代名詞が何を指しているか分からなかった

このように、文章の意味が取れなくなる理由はさまざまです。

こうした細かい間違い分析をして、毎回解決策を考えて実行すること。それによって、同じような問題や語彙、文構造が出てきたときに、きちんと読めるようになっていきます。

毎日の学習への取り入れ方

ここからは、この間違い分析を日々の学習にどう取り入れるかをお話しします。

リーディングは、1つのパッセージにつき1時間〜1時間半かけて、問題を解いて復習まで行います（かかる時間は人によって異なります）。

  1. 根拠に線を引きながら問題を解く
  2. 答え合わせをして、正誤を確認する
  3. 間違えた問題の正解の根拠を自分で探し、別の色で線を引く（10〜15分、人によってはもっとかかることもあります）
  4. なぜ間違えたのかを分析し、ノートに書く

なんとなく雑にパッセージをどんどん解いていくよりも、1つのパッセージから徹底的に学ぶほうが、確実にリーディングの本質的な力が身についていきます。

分析ノートは「定期的に振り返る」

間違い分析ノートは、作って終わりではありません。定期的に振り返るようにしましょう。

例えば週末に分析ノートを見返して、今週多かった間違いのパターンを把握し、それに対する対策ができたかを考えます。

振り返りは、試験の直前にも効果的です。自分が間違えやすいパターンを確認しておくことが、同じミスを繰り返さないことにつながります。試験の直前まで見直してから、本番に臨んでください。

おわりに｜1問の間違いを、次の1問の正解に

今回は、IELTSリーディングの本質は「根拠を探すこと」だということ、そして間違えた問題を次の学びに活かすための間違い分析の方法をお話ししてきました。

もう一度、流れをおさらいしましょう。

  1. 問題を解くときは、根拠となる本文に必ず線を引く
  2. 答え合わせをする
  3. 間違えた問題の正解の根拠に、別の色で線を引く
  4. ステップ1と3の線がなぜ一致しなかったのかを分析して、ノートに書く
  5. 分析ノートを定期的に振り返り、自分の間違いの傾向と、それに対する行動が取れたかを見直す

この方法は、私のコーチングの受講生さん全員にお伝えしている内容です。実際にこの方法で学習を進めた方は、1ヶ月でリーディングが4.0から6.0に上がっています。

リーディングのスコアを短期間で伸ばしたい方、これまでなんとなく復習をしていたという方に、ぜひ取り入れていただきたい方法です。

なんとなく解く復習から、根拠で解く復習へ。

このnoteが、あなたのリーディングのスコアアップにつながれば、こんなに嬉しいことはありません。

# 🔍 IELTSライティング｜it の使い方 完全ガイド
### スコアを下げている「it」を撲滅する

---

> **このガイドの目的**
> 「it を使ってはいけない」ではなく、「正しく使えるようになる」ことがゴールです。
> it の間違いは **CC（Coherence & Cohesion）と LR（Lexical Resource）の両方** に影響します。

---

## はじめに｜なぜ日本人は it を間違えるのか

日本語には「それ」「これ」「あれ」という指示語はありますが、
英語の it ほど**文法的な制約が厳しくありません。**

日本語では「〜は大切だ」と主語を省略できますが、
英語では必ず主語が必要なため、とりあえず it を置いてしまう癖がつきます。

```
日本語：「技術は私たちの生活を変えた。あらゆる場所で使われている。」
         ↑「あらゆる場所で」の主語は省略されている

英語（間違い）：Technology has changed our lives. It is used everywhere.
英語（正しい）：Technology has changed our lives and is now used everywhere.
```

**it が減点になる理由は「使いすぎ」ではなく「指示対象が不明確なこと」です。**

---

## PART 1｜it の正しい4つの使い方

---

### ① 仮主語の it

**構造：** `It is + 形容詞 + to不定詞 / that節`

真の主語が長い場合、文頭に it を置いて後ろに回す用法。
**これは正しい使い方です。**

```
✅ It is essential to understand the marking criteria.
✅ It is widely acknowledged that education shapes society.
✅ It is often argued that technology creates more problems than it solves.
```

> 💡 **IELTS での使い方のコツ**
> `It is + 形容詞 + that` の構文は、客観的な主張を述べるときに自然に使えます。
> ただし同じ構文を1つのエッセイで3回以上使うと LR が下がります。

---

### ② 強調構文の it

**構造：** `It is + 強調したい要素 + that / who ~`

特定の情報を強調したいときに使う構文。
**採点官に「語彙の幅がある」という印象を与えます。**

```
✅ It is the lack of education that leads to poverty.
   （貧困につながるのは教育の欠如だ）

✅ It is governments, not individuals, that should take responsibility.
   （責任を取るべきなのは個人ではなく政府だ）
```

> 💡 **IELTS での使い方のコツ**
> 主張を強調するパラグラフの冒頭や結論部分で使うと効果的です。
> Band 7以上を狙うなら1エッセイに1〜2回意識的に使いましょう。

---

### ③ 状況・天候・時間を表す it

**構造：** `It + 動詞`（主語のない文を作るための形式的な it）

```
✅ It is getting increasingly difficult to ignore climate change.
✅ It has become common for people to work remotely.
✅ It remains unclear whether this policy will succeed.
```

> 💡 **IELTS での使い方のコツ**
> `It has become〜` `It remains〜` `It is becoming〜` は
> トレンドや現状を述べるときに便利な表現です。

---

### ④ 直前の名詞を受ける it

**構造：** 直前に登場した**単数の名詞**を受ける

**これが最も間違いが多い用法です。**
「何を指しているか」が読み手に100%伝わるときだけ使います。

```
✅ The government introduced a new policy. It aims to reduce carbon emissions.
   （itが指すもの：the new policy → 明確）

❌ Technology has changed education. It is very important.
   （itが指すもの：Technology? education? → 不明確）
```

## PART 2｜よくある間違い 5選

---

### ❌ 間違い① 指示対象が不明な it

最も多い間違い。**it が何を指しているか読み手に伝わらない。**

```
❌ The internet has transformed communication and education.
   It has both positive and negative effects.

→ 「it」はインターネットを指す？コミュニケーションを指す？教育を指す？
```

```
✅ The internet has transformed communication and education.
   This technology has both positive and negative effects.

→「This technology」と明示することで誰が読んでも分かる
```

---

### ❌ 間違い② 漠然とした主語としての it

**「なんとなく主語が必要だから it を置く」パターン。**

```
❌ It is a serious problem about the environment.
   （「それ」は何？）

✅ Environmental pollution has become a serious global concern.
```

```
❌ In today's society, it is technology everywhere.
   （文として成立していない）

✅ In today's society, technology permeates every aspect of our lives.
```

---

### ❌ 間違い③ it の連続使用

同じ段落内で it が3回以上続くと、**LR（語彙の豊富さ）が下がります。**

```
❌ Social media has changed how people communicate.
   It allows people to connect globally. It also spreads
   information rapidly. However, it can cause addiction.

→ it が4回連続で単調。採点官は「語彙が限られている」と判断する
```

```
✅ Social media has transformed modern communication,
   enabling people to connect globally. This platform
   spreads information at an unprecedented speed.
   However, excessive use can lead to addiction.

→ it をなくし「This platform」「excessive use」に言い換えた
```

---

### ❌ 間違い④ 仮主語と本来の主語の混同

```
❌ It is my opinion that the government should invest more
   in education, and it will lead to long-term economic growth.

→ 前半の it は仮主語（正しい）
→ 後半の it は「投資すること」を指すが、文の構造から不明確
```

```
✅ The government should invest more in education,
   as this approach will lead to long-term economic growth.

→「this approach」と具体的に言い換えることで明確になる
```

---

### ❌ 間違い⑤ it と they の混同

**複数名詞を受けるときは they / them / their を使う。**
it は単数名詞のみ。

```
❌ Young people face many challenges today. It is difficult for them.

→「many challenges」は複数なのに it（単数）で受けている
```

```
✅ Young people face many challenges today.
   These obstacles can significantly affect their well-being.

→ These obstacles（複数）に言い換えてCCも自然に向上
```

## PART 3｜it の代わりに使える表現リスト

it の連続使用を避けるための言い換え表現です。

### 前の名詞・概念を受ける表現

| 場面 | 言い換え表現 | 例 |
|---|---|---|
| 単数の名詞を受ける | This + 名詞 | This approach / This policy / This issue |
| 複数の名詞を受ける | These + 名詞 | These factors / These challenges |
| 前述の考え全体を受ける | Such + 名詞 | Such measures / Such an approach |
| 前の文の内容全体を受ける | This means that〜 | This means that action is required. |
| 前の状況を受ける | This trend / This phenomenon | This trend is expected to continue. |

---

### 主語を具体的に言い換える表現

| 元の it | 言い換え例 |
|---|---|
| It（テクノロジー全般） | This technology / Digital innovation |
| It（政策） | This measure / The initiative |
| It（問題） | This issue / The challenge / The concern |
| It（教育） | This field / The education system |
| It（社会現象） | This phenomenon / This trend |

## PART 4｜ビフォーアフター練習問題

以下の文章の「問題のある it」を見つけて、より良い表現に直してみましょう。

---

**問題 1**

```
原文：
The use of smartphones has increased dramatically.
It is now common among all age groups. It has changed
the way people interact with each other. It can also
be addictive, which is a growing concern.
```

<details>
<summary>✅ 解答例を見る</summary>

```
改善例：
The use of smartphones has increased dramatically
and is now common among all age groups. This technology
has fundamentally changed the way people interact
with each other. However, excessive use can lead to
addiction, which is a growing concern.

【解説】
・「It is now common」→ and is now common に変えて文を統合
・「It has changed」→ This technology has changed に変えて明確化
・「It can also be addictive」→ excessive use can lead to に言い換え
```
</details>

---

**問題 2**

```
原文：
Governments should invest in renewable energy.
It will reduce carbon emissions. It is also important
for economic growth. It is clear that it is necessary
for the future.
```

<details>
<summary>✅ 解答例を見る</summary>

```
改善例：
Governments should invest in renewable energy,
as this shift would significantly reduce carbon emissions.
Furthermore, such investment is vital for long-term
economic growth. Clearly, transitioning to clean energy
is essential for a sustainable future.

【解説】
・「It will reduce」→ as this shift would reduce に変えて理由を明示
・「It is also important」→ such investment is vital に強化
・「It is clear that it is necessary」→ Clearly〜is essential にすっきり言い換え
```
</details>

---

**問題 3**

```
原文：
Many countries are facing an ageing population.
It is a serious problem. It affects the economy
and healthcare system. It means that governments
need to find new solutions.
```

<details>
<summary>✅ 解答例を見る</summary>

```
改善例：
Many countries are facing a rapidly ageing population,
which poses a serious challenge. This demographic shift
places increasing pressure on both the economy and
the healthcare system. Consequently, governments must
urgently seek innovative solutions.

【解説】
・「It is a serious problem」→ which poses a serious challenge に変えて前文に統合
・「It affects〜」→ This demographic shift に言い換えて具体性UP
・「It means that」→ Consequently に変えてCC向上
```
</details>

## まとめ｜it チェックリスト（提出前に確認）

提出前に自分の答案でチェックしてみましょう。

- [ ] it が連続して3回以上使われている段落がないか
- [ ] 各 it の指示対象が明確に1つに特定できるか
- [ ] 複数名詞を it で受けていないか（they / these を使っているか）
- [ ] 漠然とした主語として it を使っていないか
- [ ] 仮主語・強調構文の it は正しく使えているか

**3つ以上チェックできない場合は、it を This + 名詞 に言い換えることを検討してください。**

---

> 📌 **最後に**
> it を「使ってはいけない」と覚えるのではなく、
> **「指示対象が明確なときだけ使う」** と覚えてください。
> 迷ったときは `This + 名詞` に言い換えると、CC・LR の両方が自然に上がります。

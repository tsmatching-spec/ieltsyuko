## 【1枚目】フック：パート2のメモを取っていなかった

```
今日の面談で
ハッとした瞬間がありました。

スピーキングのスコアが
なかなか上がらない方と話していて

「パート2のメモ、
 どうやって取ってますか？」

と聞いたら

「取っていませんでした」
```

## 【2枚目】なぜメモが重要なのか

```
パート2は唯一、
1分間の準備時間があります。

この時間があるのに
アピールできていないとしたら
それはとてももったいない。

私がすすめるメモの取り方は
「内容」ではなく
「使いたい語彙・構文」を書くこと。

本番でど忘れしやすいのは
話の流れではなく「言葉」です。
```

## 【3枚目】スコアの仕組みを知っていますか？

```
6.5を取るのに必要なこと、
実は多くの人が知りません。

スピーキングは4つの評価基準で採点されます。
・流暢さ
・まとまり
・語彙
・文法・発音

オーバーオール6.5 ＝
この4つのうち、少なくとも2つで
「7」を取る必要があります。

「全部6.5でいい」ではなく
「どこで7を取るか」を決める戦略が必要です。
```

## 【4枚目】100個覚えるより3つを使いこなす

```
よく聞く悩み：

「単語を覚えても
 本番で使えない」

理由は、使えないものを
覚え続けているから。

1週間に100個覚えても
本番で使えるのは
最もよく開けた「引き出し」だけ。

今週は3つだけ決めてください。
どんな質問が来ても
その3つを使う練習をする。

それが本番で使える語彙になります。
```

---

## 【5枚目】「練習のための練習」から抜け出す

```
リーディング 7.0
リスニング 6.0

この差がある場合、
多くは「聞こえない」ではなく
「音で認識できていない」こと。

文字で見れば分かる。
でも音になると取れない。

それはシャドーイングと
スペル・音のひも付けで変わります。

そして最後に1つ。

「練習でできても本番でできない」
のはなぜか。

初見の問題に対しても
同じことができるように練習していないから。

本番を意識した練習が
スコアを変えます。
```

# 面談からのストーリーズ（3枚）
## テーマ：生徒との面談で気づいたこと ＋ スピーキング対策の落とし穴

> 面談の内容をもとに作成

---

## 【1枚目】フック：パート2のメモを取っていなかった

```
今日の面談で
ハッとした瞬間がありました。

「パート2のメモ、
 どうやって取ってますか？」

と聞いたら

「取っていませんでした」

パート2は唯一、
1分間の準備時間があります。

ここで語彙・構文をメモしておくだけで
スコアは変わります。

「内容」ではなく
「使いたい言葉」を書くのがコツです。
```

---

## 【2枚目】6.5の正体：「全部6.5」は存在しない

```
スピーキング6.5を取るために
知っておいてほしいこと。

採点は4基準の平均です。
・流暢さ
・まとまり
・語彙
・文法・発音

オーバーオール6.5 ＝
この4つのうち最低2つで「7」が必要。

「全部6.5でいい」ではなく
「どこで7を取るか」を決める。

この視点を持つだけで
対策が変わります。
```

---

## 【3枚目】100個より3つ ＋ 本番を意識した練習

```
「単語を覚えても本番で使えない」

これはよくある悩みです。

100個覚えても
使えるのは一番よく開けた「引き出し」だけ。

今週は3つに絞って
どんな質問が来てもその3つを使う練習を。

そして、練習でできても
本番でできないのはなぜか。

初見の問題でも同じことができるように
練習していないから。

本番を意識した練習が
スコアを変えます。

─────────────────
個別相談では、あなたの状況を分析して
何から変えるべきかを一緒に整理します。

6月18日（火）19:00〜
LINEで「相談希望」と送ってください。
```

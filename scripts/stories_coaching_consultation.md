# ネタ①：パート2のメモを取っていなかった

## 【①-1】フック

```
今日の面談で
ハッとした瞬間がありました。

スピーキングがなかなか上がらない方と話して

「パート2のメモ、
 どうやって取ってますか？」

と聞いたら

「取っていませんでした」
```

## 【①-2】なぜもったいないのか

```
パート2は唯一、
1分間の準備時間があります。

この時間は「内容を考える時間」
だと思っていませんか？

実はそれだけでは不十分。

採点官に「語彙・文法のアピール」を
する絶好のチャンスです。

メモしておかないと
本番で言葉が出てこなくなります。
```

## 【①-3】正しいメモの取り方

```
私がすすめるメモの取り方：

✅「内容」ではなく「使いたい言葉」を書く

話の流れは覚えていられます。
でも本番でど忘れするのは「言葉」です。

たとえば
使いたい構文・思い出せなくなりそうな単語
→ これだけメモしておく

1分間でこれをやるだけで
スコアは変わります。
```

# ネタ②：6.5の正体「全部6.5」は存在しない

## 【②-1】フック

```
スピーキング6.5を目指している方へ

「全部6.5を取れば6.5になる」

そう思っていませんか？

実は、それは正確ではありません。
```

## 【②-2】採点の仕組み

```
スピーキングは4つの基準で採点されます。

・流暢さ
・まとまり
・語彙
・文法・発音

この4つの平均がスコアになります。

つまり
オーバーオール6.5 ＝
4つのうち最低2つで「7」を取る必要があります。

「全部6.5」ではなく
「どこで7を取るか」が重要です。
```

## 【②-3】戦略の立て方

```
この視点を持つと対策が変わります。

たとえば
語彙は少し自信がある → ここで7を狙う
文法は安定している → ここでも7を狙う

得意なところを伸ばして
2つで7を取りにいく。

「全部満遍なく」より
「どこかで確実に7」が
6.5達成の近道です。
```

# ネタ③：100個より3つを使いこなす

## 【③-1】フック

```
「単語をたくさん覚えているのに
 本番で全然使えない」

この悩み、すごくよく聞きます。

理由は、覚え方にあります。
```

## 【③-2】引き出しの話

```
100個覚えても
本番で使えるのは
「一番よく開けた引き出し」だけです。

緊張した瞬間、頭は
いつも使っている言葉に逃げます。

1回しか練習しなかった表現は
本番では出てきません。
```

## 【③-3】正しい練習法

```
今週はこれを試してみてください。

覚える表現を「3つだけ」に絞る。

どんな質問が来ても
その3つを使う練習をする。

1週間後には
その3つが「すぐ開く引き出し」になっています。

量より反復。
それがスピーキングスコアを上げる近道です。
```

# ネタ④：リーディング7点・リスニング6点の差の正体

## 【④-1】フック

```
リーディング 7.0
リスニング 6.0

この差がある方に
よくお伝えすることがあります。

「聞こえていないのではなく
 音で認識できていないんです」
```

## 【④-2】なぜ差が生まれるのか

```
文字で見れば意味がわかる。
でも音になると取れない。

これは英語力の問題ではなく
「音とスペルのひも付け」の問題です。

日本語話者に多いのが
・th、v、l/r の音の区別
・連結した音（going to → gonna）
・アルファベットの音（b と v など）

スクリプトを読めば理解できるのに
聞き取れないのは、ここが原因です。
```

## 【④-3】改善の方法

```
改善のポイントは2つ。

1. シャドーイング
   → 音とリズムを体に覚えさせる

2. 聞き取れなかった箇所のスペル確認
   → 音とスペルをセットで記憶する

「量を聞く」より
「なぜ取れなかったかを確認する」

この習慣がリスニングを変えます。
```

# ネタ⑤：練習のための練習から抜け出す

## 【⑤-1】フック

```
「練習ではできるのに
 本番になるとできない」

スピーキングでこれを感じている方、
多いと思います。

原因は1つです。
```

## 【⑤-2】なぜ本番でできないのか

```
練習でできるのは
「見慣れた問題」「準備した答え」だから。

でも本番は初見の問題です。

練習で同じ問題を繰り返しても
初見への対応力はつきません。

本番を想定していない練習は
本番で使えない練習になります。
```

## 【⑤-3】本番を意識した練習とは

```
初見の問題に対して
今まで練習してきたことが
そのまま出せるか。

これが本番を意識した練習です。

具体的には

・見たことのない問題をランダムに出す
・1発録音して、見直さずに提出する
・準備なしで答えてみる

「できた感覚」ではなく
「初見でもできた」を積み重ねてください。
```

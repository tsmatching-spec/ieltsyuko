# ネタ①：パート2のメモを取っていなかった

## 【①-1】
```
今日の面談でハッとしました。

「パート2のメモ、どう取ってますか？」

「取っていませんでした」

パート2には1分間の準備時間があります。
この時間を使えていないのは、もったいない。
```

## 【①-2】
```
パート2の準備時間は「内容を考える時間」だけではありません。

語彙・構文をアピールする準備をする時間です。

メモしておかないと、本番で言葉が出てこなくなります。
```

## 【①-3】
```
おすすめのメモの取り方：

「内容」ではなく「使いたい言葉」を書く。

話の流れは覚えていられます。
でもど忘れするのは「言葉」です。

この1分間の使い方でスコアが変わります。
```

# ネタ②：「全部6.5」は存在しない

## 【②-1】
```
スピーキング6.5を目指している方へ。

「全部6.5を取れば6.5になる」

そう思っていませんか？

実は、それは正確ではありません。
```

## 【②-2】
```
スピーキングは4基準の平均でスコアが決まります。
（流暢さ・まとまり・語彙・文法）

オーバーオール6.5 ＝
この4つのうち、最低2つで「7」が必要。

「全部6.5」ではなく「どこで7を取るか」が重要です。
```

## 【②-3】
```
得意な基準で確実に7を取りにいく。

語彙に自信がある → そこで7を狙う
文法が安定している → そこでも7を狙う

「全部満遍なく」より「どこかで確実に7」が
6.5達成の近道です。
```

# ネタ③：100個より3つを使いこなす

## 【③-1】
```
「単語をたくさん覚えているのに
本番で全然使えない」

この悩み、すごくよく聞きます。

理由は覚え方にあります。
```

## 【③-2】
```
100個覚えても、本番で使えるのは
「一番よく開けた引き出し」だけです。

緊張すると、いつも使っている言葉に逃げます。
1回しか練習しなかった表現は本番では出てきません。
```

## 【③-3】
```
今週は覚える表現を「3つだけ」に絞ってください。

どんな質問が来ても、その3つを使う練習をする。

1週間後にはその3つが「すぐ開く引き出し」になります。
量より反復。これがスコアを上げる近道です。
```

# ネタ④：リーディング7点・リスニング6点の差の正体

## 【④-1】
```
リーディング 7.0 / リスニング 6.0

この差がある方によくお伝えすること。

「聞こえていないのではなく、
 音で認識できていないんです」
```

## 【④-2】
```
文字で見れば意味がわかる。
でも音になると取れない。

これは英語力の問題ではなく
「音とスペルのひも付け」の問題です。

スクリプトを読めばわかるのに聞き取れない方は、ここが原因です。
```

## 【④-3】
```
改善のポイントは2つ。

① シャドーイング → 音とリズムを体に覚えさせる
② 聞き取れなかった箇所のスペル確認 → 音とスペルをセットで記憶

「量を聞く」より「なぜ取れなかったか確認する」習慣がリスニングを変えます。
```

# ネタ⑤：練習のための練習から抜け出す

## 【⑤-1】
```
「練習ではできるのに、本番になるとできない」

スピーキングでこれを感じている方、多いと思います。

原因は1つです。
```

## 【⑤-2】
```
練習でできるのは「見慣れた問題」「準備した答え」があるから。

でも本番は初見の問題です。

同じ問題を繰り返す練習は、初見への対応力をつけません。
```

## 【⑤-3】
```
本番を意識した練習とは、
初見の問題でも今まで練習してきたことが出せるか、です。

・見たことのない問題でランダムに答える
・1発録音して見直さずに提出する

「できた感覚」より「初見でもできた」を積み重ねてください。
```

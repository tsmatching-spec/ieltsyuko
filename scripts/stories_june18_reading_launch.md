## 【2枚目】先に解くべき問題タイプ

```
✅ 先に解くべき問題タイプ

1. 空所補充（Sentence completion）
   → 答えが本文に出てくる順番どおり

2. Yes / No / Not Given
   → 段落ごとに対応しやすい

3. 見出し選択（Heading matching）
   → 各段落の要旨をつかむ練習になる

これらは「本文を読みながら解ける」問題。
時間を節約できます。
```

---

## 【3枚目】後回しにすべき問題タイプ

```
❌ 後回しにすべき問題タイプ

1. マッチング問題
   → 本文全体を行き来する必要がある

2. 複数選択問題（Multiple choice）
   → 引っかかりやすく時間を取られる

3. 要約完成（Summary completion）
   → 読む範囲が広い

この順番を変えるだけで
「時間が足りない」が解消された生徒さんがいます。
```

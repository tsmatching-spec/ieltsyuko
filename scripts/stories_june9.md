## 【2枚目】Task Achievement の説明

```
Task 1・Task 2 どちらも、
まず採点官が見るのは

「Task Achievement（課題への回答）」

どれだけ上手に書いても
"問いに答えていない"と判定されると
ここで大きく点を落とします。
```

---

## 【3枚目】DMスクリーンショット（「添削したことがない」）

```
先日こんなDMをいただきました。

「Task 1を添削したことがないんですが
 何から始めればいいですか？」

この質問、すごく大事なんです。
添削よりも先にやるべきことがあります。
```

---

## 【4枚目】Task Achievement ズレの具体例

```
たとえば Task 1 でグラフの問題が出たとき

❌ やってしまいがちなこと
→ 数字を全部書こうとする
→ 自分の意見を入れてしまう

✅ 採点官が求めていること
→ 全体の傾向を捉えて書く
→ 客観的なデータの比較・説明
```

---

## 【5枚目】Task 2 のよくある TA のズレ

```
Task 2 も同様です。

「Discuss both views」と書いてあるのに
自分の意見だけ書いてしまう…

これが TA のスコアを下げる
最も多いパターンです。
```

---

## 【6枚目】解決策の提示

```
まず最初にやること：

1. 問題文を3回読む
2. "何を求められているか"を日本語で書き出す
3. その上で書き始める

これだけで TA のスコアが
変わる人が多いんです。
```

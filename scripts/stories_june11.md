## 【3枚目】問題の核心

```
6.5 → 7.0 の壁、
実は「勉強量」の問題じゃないことが多いです。

何が問題なのか。

それは「採点官が何を見ているか」と
「自分が意識していること」のズレです。
```

---

## 【4枚目】採点基準の説明

```
IELTS ライティング は 4 つの基準で採点されます

1. Task Achievement（課題への回答）
2. Coherence & Cohesion（文章のつながり）
3. Lexical Resource（語彙）
4. Grammatical Range（文法）

6.5 止まりの方は
多くの場合、1 か 2 に課題があります。
```

---

## 【5枚目】具体的な改善ポイント

```
たとえば Task 2 で

「あなたの意見を書きなさい」の問題。

✅ 採点官が求めること
→ 自分の立場を明確に、
  論拠を具体的に示す

❌ よくある間違い
→ 両方の立場を均等に書いてしまう
```

## 1. 生徒さんの事例：6.5 → 8.5

| 項目 | 内容 |
| --- | --- |
| 期間 | 6週間 |
| リスニングスコア | 6.5 → **8.5**（+2.0、ご本人のベストスコア） |
| 変えたこと | 聞き流しをやめる／間違いの分析／コンテンツシャドーイング |

### 学習を変える前の状態

- 毎日 **約1時間** 英語を聞く習慣はできていた
- 聞いていたのは BBC、興味のあるポッドキャスト、BBC 6 Minute English など
- 悩み①：**集中力が切れてしまう**
- 悩み②：**Part 2 と Part 4 が苦手**
- 1回目で聞き取れなくても、**2回目に聞くと9割は正解できる**

👉 リスニングの土台はできている。でも、スコアを上げるには「何か」を変える必要がありました。

その「何か」が **聞き流し** でした。

---

## 2. 「聞き流し」がIELTS対策にならない2つの理由

> 趣味や楽しみとして聞き流すことは問題ありません。ただし、**IELTS対策としては効率的ではありません。**

### 理由① 正しく理解できているか確認できない

リスニング試験で求められるのは、主にこの2つです。

1. **音を認識できるか**
2. **意味を理解できるか**

（IELTSではさらに、設問を正しく読めるリーディング力や、正しいスペルで書けるかも見られます。）

聞き流しでは、音を認識できているか・意味を理解できているかを **確認する手段がありません**。
スクリプトや音のひとつひとつを意識せず、文脈全体から「だいたいこんなことを言っている」と理解しようとするため、どうしても **「なんとなく聞いている」状態** になってしまいます。

### 理由② 語彙のレベル・種類が本番と違う

IELTSのリスニングは、日常会話・道案内・講義など **現実にありそうな場面** で作られています。

一方で、普段聞いているポッドキャストやYouTubeは…

- 語彙のレベルがとても高い、または逆に **カジュアルすぎる**
- 好きな分野の話なので、**背景知識で推測して理解できてしまう**

使われる語彙のレベル・分野、必要な背景知識のどれをとっても、本番とは大きな差があります。

✅ **IELTS対策期間中は、聞き流しをいったんお休みしましょう。**

---

## 3. まずは「聞き取れない原因」を見分けよう

リスニングで聞き取れない原因は、主に2つです。

| 原因 | どんな状態？ | 対策の方向 |
| --- | --- | --- |
| **A. 語彙の意味がわからない** | スクリプトを見ても意味がわからない | 語彙力を強化する |
| **B. 音が聞こえない** | スクリプトを見れば意味はわかるのに、音で認識できない | 音 → 意味の処理を鍛える |

### セルフチェック

問題を解いたあと、聞き取れなかった箇所のスクリプトを見てみましょう。

- [ ] スクリプトを見たら、ほとんど意味がわかる → **B（音が聞こえない）** タイプ
- [ ] スクリプトを見ても、わからない単語が多い → **A（語彙）** タイプ
- [ ] 2回目に聞けば正解できる問題が多い → **B** タイプの可能性が高い

今回の生徒さんは **B（音が聞こえない）** が圧倒的に多く、スクリプトを見ればすべて理解できる状態でした。
つまり、**1回で音を聞き取れていないこと** がスコアが上がらない原因でした。

---

## 4. 学習法① なぜ1回で聞き取れなかったのかを分析する

問題を解いたら、間違えた問題ごとに **「なぜ1回で聞き取れなかったのか」** を細かく書き出します。
理由をはっきりさせることで、同じ間違いを繰り返さないように意識できるようになります。

### よくある原因の例

- 集中力が切れてしまった
- 問題文を先に読めず、焦って聞き逃した
- 単語を単純に聞き逃した
- （スクリプトを見ても）語彙の意味がわからなかった

### 間違い分析テンプレート

Notionで使う場合は、この表をデータベースに変換すると便利です。

| 日付 | テスト / Part | 問題番号 | 聞き取れなかった語句 | 原因 | スクリプトを見たら理解できた？ | 次回意識すること |
| --- | --- | --- | --- | --- | --- | --- |
| 例：10/27 | Cam18 Test1 / Part2 | 14 | *adjacent to* | 問題文の先読みが間に合わず焦った | はい | Part 2開始前に14〜16の設問を先に読む |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

## 5. 学習法② コンテンツシャドーイング

シャドーイングにはいくつか種類がありますが、今回おすすめするのは **コンテンツシャドーイング** です。
**音声を追いかけて声に出しながら、同時に意味を理解していく** 方法です。

### コンテンツシャドーイングをおすすめする3つの理由

1. **集中力が高まる**
   音を注意深く聞きながら同時に意味を理解するのは簡単ではありません。自然と集中力が鍛えられます。
2. **音声処理が「自動化」される**
   音を認識して、それを自動的に意味に変換できる状態をつくります。音から意味への切り替えを瞬時にできるように鍛えます。
3. **すでに知っている知識が強化される**
   知っている語彙や表現、覚えたばかりの表現が出てくると定着しやすくなります。声に出すので、**スピーキングにも活かせます**。

---

## 6. コンテンツシャドーイングのやり方（4ステップ）

### STEP 1：スクリプトを1つ選ぶ
- 本番に近い語彙・場面の音源を選びましょう（例：公式問題集のリスニング音源とスクリプト）
- 苦手なPartがあれば、そのPartから選ぶのがおすすめです（今回の生徒さんは **Part 2・Part 4** が苦手でした）

### STEP 2：スクリプトを完全に理解する
- わからない単語・表現はすべて調べる
- 「読めば100%わかる」状態にしてから音声に進みます

### STEP 3：音声を聞きながら、同時に声に出して意味を理解する
- 聞こえた音を **その場で** 声に出す
- 同時に **意味を理解する** ことを意識する

### STEP 4：スピードを調整しながら、1倍速を目指す
- 標準スピードが難しい場合は **0.5倍速 → 0.75倍速 → 1倍速** と上げていく
- **1つのスクリプトを1週間** 続けて、1倍速でついていけるまで練習する

> ⚠️ **注意**
> - 目的は「発音を良くすること」でも「ただ音読すること」でもありません
> - **聞こえた音を発しながら、同時に意味を理解する** ことが一番大切です

### スピードを上げていくと…

- 音から意味を理解するスピードがどんどん速くなる
- 本番の音源が **ゆっくりに聞こえる** ようになる
- 余裕を持って、音の認識と意味の理解ができるようになる

## 7. 6週間プラン（例）

1週間に1スクリプトのペースで進めるプランです。毎日の練習量はご自身の生活に合わせて調整してください。

| 週 | シャドーイング | 問題演習・分析 |
| --- | --- | --- |
| Week 1 | スクリプト① を 0.5倍速 → 1倍速まで | 1セット解いて「間違い分析」を始める |
| Week 2 | スクリプト② | 1セット解いて分析。原因の傾向を確認 |
| Week 3 | スクリプト③（苦手Partから選ぶ） | 1セット解いて分析 |
| Week 4 | スクリプト④（苦手Partから選ぶ） | 1セット解いて分析。前半3週と原因を比較 |
| Week 5 | スクリプト⑤ | 本番と同じ条件で1セット解いて分析 |
| Week 6 | スクリプト⑥ | 本番と同じ条件で1セット解き、最終チェック |

### 毎日のチェックリスト

- [ ] 今週のスクリプトでシャドーイングをした
- [ ] 意味を理解しながら声に出せた（ただの音読になっていない）
- [ ] 今日のスピード：□ 0.5倍　□ 0.75倍　□ 1倍
- [ ] 聞き流しではなく、集中して聞く時間をつくった

### 週の終わりのふり返り

- 1倍速でついていけた？：
- 意味がとれなかった箇所：
- 来週選ぶスクリプト：

## まとめ

- リスニング6.5で止まっている人は、**聞き流しをやめる** ところから始めましょう
- 聞き取れない原因が **「語彙」なのか「音」なのか** を見分ける
- 間違えた問題は **「なぜ1回で聞き取れなかったのか」** を分析する
- **コンテンツシャドーイング** で、音から意味への処理を自動化する
- **1スクリプトを1週間**、1倍速でついていけるまで練習する

> 人によって課題や合う学習法は違います。
> ただ、今「聞き流し」を学習法として取り入れている方は、一度やめて別の方法に切り替えたほうが、IELTSリスニング対策としては効果的な可能性が高いです。

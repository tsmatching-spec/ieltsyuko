**調査日:** 2026年5月22日

## 1. 再生されている添削動画のタイトルパターン

調査で確認できた再生数の多い添削系動画タイトルには、明確な共通パターンがある。

| タイトル例 | 特徴 |
|---|---|
| From Band 6.5 to 8: IELTS Writing Makeover | スコア変化を数字で見せる |
| The Writing Makeover That Took an Essay From 6.5 to 9 | "Makeover" ＋ 変化の数字 |
| How Anyone Can Jump from Band 6 to 8.5 in ONE Month | "Anyone" ＋ 具体的な期間 |
| Live IELTS Writing Task 2 Essay Correction | "Live" で臨場感を演出 |

**→ 共通点：「変化の前後」を数字で示す。「6.5 → 8」という形が最も強い。**

---

## 2. 再生される添削動画の構成パターン（3タイプ）

### タイプA：Makeover 型（最も再生数が多い）

```
① フック（0〜30秒）
   「このエッセイのスコアは6.5でした。でも、たった3か所直したら8になります」
   ─ 最初にスコアを見せて視聴者を引き込む

② 元エッセイを読む
   ─ Before を一緒に確認。「どこがまずいか」を視聴者に考えさせる

③ 問題点を解説（2〜4か所に絞る）
   ─ 採点基準（TR / CC / LR / GR）ごとに整理して指摘

④ 改善版（After）を見せる
   ─ 変化を視覚的にわかりやすく（Before/After を並べる）

⑤ まとめ・CTA
   ─ 「あなたのエッセイもコメントに貼ってください」
```

### タイプB：Live Correction 型（E2 IELTS などが使用）

```
① ライブ感を強調したオープニング
② 視聴者から募集したエッセイを画面に映す
③ リアルタイムで読みながら添削・コメント
④ スコアの推定を発表
⑤ 「次回も添削エッセイを募集します」でエンゲージメントを循環させる
```

### タイプC：Q&A 型（学習者の質問に答える）

```
① 視聴者からの質問（または自分が書いたエッセイ）を紹介
② 質問に1問ずつ丁寧に回答
③ 改善例を示す
─ IELTSゆうこの現在の動画はこれに近い
```

## 3. 再生数を上げる「フック」の法則

調査から見えた共通の法則：

**① 最初の10秒でスコアを見せる**
視聴者は「自分に関係あるか」を最初の数秒で判断する。
「このエッセイは想定7.0です」を冒頭で言うのが正解。

**② タイトルとサムネイルに数字を入れる**
- NG：「添削してみた」
- OK：「想定7.0エッセイのどこを直した？」
- 最強：「6.5 → 7.5 に上げた3か所」

**③ 「あるある感」を煽る**
視聴者が「自分も同じミスをしている」と感じる瞬間をなるべく早く作る。
「日本人が必ずやるミス」「バンド6で詰まる人が全員やっていること」など。

**④ 視聴者参加を促す**
「コメント欄にエッセイを貼ってください」という一言が、コメント数を大幅に増やす。
YouTubeアルゴリズムはコメント数を評価するため、再生数にも影響する。

## 4. IELTSゆうこの現在の動画 vs 再生される動画の比較

| 要素 | 現在の動画 | 再生される動画 |
|---|---|---|
| タイトル | 「実際の添削」 | 「6.5 → 7.5 に上げた3か所」など数字あり |
| フック | 想定スコアを動画中で発表 | **冒頭10秒以内**でスコア発表 |
| 構成 | Q&A型（質問に回答） | Makeover型（Before/After の変化を体感させる） |
| 視聴者参加 | 「コメントに貼って」とエンディングで言及 | 動画の途中・複数回で促す |
| Before/After | 最後に改善版を紹介 | **冒頭で「After のスコア」を見せてから Before に戻る** |

## 5. 推奨：次回の添削動画で取り入れるべき要素

### ① タイトルを変える
```
現在：【実際の添削】バンド7.0エッセイのどこを直した？
改善：【添削】6か所直したら想定7.0になった！テレビと子どもの発達
```

### ② オープニングを「逆算構成」にする
```
現在：「今日は添削動画をやります」→ エッセイ紹介→スコア発表
改善：「このエッセイ、想定スコア7.0です。でも直した箇所は6か所あります。
     どこだと思いますか？」→ Before を見せる → 添削
```
→ 視聴者が「探しながら見る」状態になり、離脱率が下がる。

### ③「あなたのエッセイも添削します」という定期企画にする
- 毎月1〜2本の添削動画を定例化
- コメント欄またはDMでエッセイを募集
- 採用された方には添削動画に名前（ニックネーム）を掲載
→ コメント数・ファンのロイヤルティが上がる

### ④ サムネイルに「赤ペン添削」の視覚を入れる
- Before のエッセイに赤ペンが入った画像が最も目を引く
- 左に Before（添削前）、右に「7.0」などスコアを大きく表示

## 6. まとめ：IELTSゆうこが取るべき差別化ポイント

英語圏の大手チャンネル（E2 IELTS など）が「英語で添削」をしているのに対して、
IELTSゆうこの強みは**「日本語で、日本人特有のミスを指摘できる」**こと。

特に以下の要素は他にない：
- 日本語で書いた構成メモ（骨格）をエッセイに繋げる解説
- 日本人が質問してくる「mayとcanの違い」「結論の締め方」などの疑問に答える
- 日本の例（東大の研究、ナーサリー事例）が英語でどう使えるかを示す

これを**「Makeover フォーマット」＋「日本人特有の解説」**という形でパッケージすると、
日本語IELTS YouTube では唯一無二のコンテンツになる。
